# 天气数据源接入说明

晴暖天气支持多数据源并发拉取 + 加权聚合。本文说明各数据源的获取方式、配置位置与默认优先级。

## 数据源总览与默认优先级

| 优先级 | 源 ID | 名称 | 凭证 | 数据能力 | 权重 |
|---|---|---|---|---|---|
| 1 | `amap` | 高德天气 | 需 Key（个人认证免费） | 实况 + 4 天预报（中国气象局数据） | 0.88 |
| 2 | `nmc` | 中央气象台 | 免密钥 | 实况 + 多日预报 + 昨日（默认第一优先） | 0.90 |
| 3 | `qweather` | 和风天气 | 需 API Host + Key | 实况 + 24h 逐时 + 7 天 + 预警 | 0.85 |
| 3 | `caiyun` | 彩云天气 | 需 Token/V3 凭证 | 分钟级降水 + 48h 逐时 | 0.85 |
| 4 | `openmeteo` | Open-Meteo | 免密钥 | 15 天预报 + 全球覆盖 | 0.80 |
| 5 | `metno` | MET Norway | 免密钥（需署名） | 全球任意坐标 9 天预报 | 0.75 |
| - | `xiaomi` | 小米天气 | 实验性 | 设备本地优先 | 0.70 |

**默认启用**：`中央气象台 + Open-Meteo`（零配置可用）。

**优先级规则**（设置 → 天气数据源与优先级，可拖动排序）：

1. 勾选的源会**并发请求**，全部成功时按上表权重**加权聚合**（温度、湿度等取加权值，逐时/多日取更全的源）；
2. 排在最前且成功的源决定整体天气现象与数据标注；
3. 某源失败不影响其余源，错误在设置页可见；
4. 建议配置：国内日常用「中央气象台 + Open-Meteo」即可；注册了 Key 后可加选「高德」「和风」提升精度（区县级 + 预警）；海外城市加选「MET Norway」。

## 各源开通指引

### 高德天气（amap）

1. 打开 [console.amap.com](https://console.amap.com) 注册并完成**个人开发者认证**（支付宝实名）；
2. 「应用管理 → 创建新应用」→ 添加 Key，平台选 **Web 服务**；
3. 复制 Key，粘贴到 App 设置中「高德天气」选项下的输入框；
4. 免费额度：天气预报约 900 万次/月（2025 年起月配额制），实况 + 未来 4 天预报；
5. 定位方式：自动用当前经纬度逆地理编码换取 adcode，无需手动填城市代码。

### 和风天气（qweather）

1. 打开 [console.qweather.com](https://console.qweather.com) 注册账号，创建**免费订阅**项目并生成 KEY；
2. 在控制台「设置 → 开发者信息」查看你的 **API Host**（2024 年后新账号为专属域名，形如 `abcxyz.qweatherapi.com`；老账号可用 `devapi.qweather.com`）；
3. 把 API Host 和 Key 分别填入 App 设置中「和风天气」选项下的两个输入框；
4. 免费额度约 5 万次/月（2025 年 Console V4 后超出部分按量计费，可设用量上限防扣费）；
5. 提供区县级精度、灾害预警、空气质量、逐时与 7 天预报。

### 彩云天气（caiyun，已有）

- V1 Token：[dashboard.caiyunapp.com](https://dashboard.caiyunapp.com) 注册获取，免费版含分钟级降水与 48h 逐时；
- V3：开放平台 AppKey + App Secret 签名接入。

### MET Norway（metno）

- 免密钥，开箱即用；数据由挪威气象局生产，全球任意经纬度 9 天预报；
- 依 CC BY 4.0 要求，App 内已注明数据来源（MET Norway / yr.no）；
- 请求带唯一 User-Agent 并做了缓存节流，个人使用远低于其 20 次/秒限制。

## 常见问题

- **勾选了需要凭证的源但没填 Key**：该源会自动跳过并在错误列表提示，不影响其他源；
- **聚合后的数据是哪来的**：设置页数据源卡片与首页数据标注会显示各源贡献字段；
- **想只用某一个源**：取消勾选其他源，把目标源拖到第一位。
